# Skills del proyecto

Claude Code las carga solas al abrir este repositorio. Cada skill de terceros trae `ORIGEN.md` (repositorio, versión y licencia) y fue revisada antes de agregarla. Las reglas de `CLAUDE.md` y `docs/MEMORIA.md` mandan sobre cualquier skill.

| Área | Skills |
| --- | --- |
| Propias (marca y Nicaragua) | ganchos-video-corto-nicaragua, textos-de-captura-marca, copywriting-persuasivo-legal |
| Calidad web y pruebas | webapp-testing (Anthropic), react-best-practices y web-design-guidelines (Vercel; pautas copiadas y fijas, sin descargas) |
| Seguridad | codeql, supply-chain-risk-auditor, agentic-actions-auditor, differential-review, sharp-edges (Trail of Bits) |
| Diseño y movimiento | design-motion-principles |
| SEO y marketing | seo-audit, ai-seo, programmatic-seo, schema, site-architecture, copywriting, copy-editing, social, cro, signup, aso, community-marketing, emails, marketing-plan (Corey Haines) |
| Forma de trabajar | systematic-debugging, verification-before-completion, writing-plans, test-driven-development (obra/superpowers); grill-me, handoff, diagnosing-bugs, code-review (Matt Pocock); karpathy-guidelines |

No se agregaron, a propósito:
- firebase-apk-scanner: crea cuentas y escribe datos de prueba en Firebase real.
- impeccable: descarga y ejecuta un programa al empezar.
- brainstorming y using-superpowers: levantan un servidor local u obligan a usar skills en todo.
- Skills de iOS y Expo (la app es Flutter), y las que publican o se conectan a cuentas por su cuenta.
